# data/

Place the following files in this directory before running:

1. `nkjv.sqlite3` — your existing NKJV SQLite Bible database
   - Table: `bible`
   - Columns: `Book INT, Chapter INT, VerseNumber INT, Verse TEXT`
   - 31,102 rows (full KJV)

The following files are auto-generated by the build process:

2. `bible_vectors.index` — generated by `python build_vector_db.py` (Phase 3A)
3. `bible_verse_map.pkl` — generated by `python build_vector_db.py` (Phase 3A)

Do not commit the .db file or generated vector files to git.
