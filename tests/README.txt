# tests/

Place the following file here before running Phase 5:

`test_audio.wav` — 30-second WAV file, 16kHz mono, someone clearly saying:
    "John chapter three verse sixteen"
    "Romans chapter eight verse one"
    "The Lord is my shepherd"

If this file is absent, Phase 5 Gate A will be skipped automatically.
The agent will log a blocker and continue with Gate B (live microphone only).

You can record this file with any microphone using Audacity or similar.
Export settings: WAV, 16000 Hz, Mono.
