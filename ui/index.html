MultiVerse broadcasts the current verse as a real NDI video source — vMix (or any NDI receiver) adds it like a normal camera input. The projector window above is an alternative fallback (via vMix's own Desktop Capture) if you'd rather not install the NDI runtime.
1. Install the free NDI Runtime (or NDI Tools) from ndi.video once on the machine running MultiVerse.
2. pip install cyndilib pillow --break-system-packages, then start MultiVerse as usual — the NDI source starts automatically if [ndi] enabled = true in config/config.ini.
3. In vMix: Add Input → NDI — the source named (by default) MultiVerse appears in the list automatically on the same network.
4. Add it to a layer/overlay channel as with any other source. It updates automatically whenever a verse is auto-displayed, and clears when you go off-air.

Full details, troubleshooting, and every config option: see NDI_SETUP.md in the project folder.
